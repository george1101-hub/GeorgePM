# 研发交付模板

默认实现为单文件 HTML：目录导航与正文、功能卡内流程图/同功能真实截图配对；样式与资源内嵌。用户指定 Markdown 时复用下列内容结构。

## 0. 文档说明与来源
版本、日期、当前状态、怎么读；来源文件/版本/摘要、已确认决议与范围。
信息架构/路由、全局规则、权限、状态词汇和事件口径按实际项目编写。

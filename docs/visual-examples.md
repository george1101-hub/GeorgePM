# 阶段二配图说明

第一张展示作者现有工作流的真实原型脱敏截图；第二张使用原创“会议室预约”场景介绍线框扩展路线。两图均不作为真实服务或完整功能已验收的证据。

## 高保真沙盒分屏

![高保真沙盒排行榜页真实原型脱敏截图：左侧路由、中央排行榜画布与右侧说明，无弹窗](images/stage2-sandbox-split.png)

- 顶部工具栏：保留 demo、需求评审、UI list 三种查看模式。
- 左侧页面树：在版本、端别和页面层级中找到当前视图。
- 中央产品画布：体验当前页面及组件状态。
- 右侧说明：分为需求说明、测试要点、开发说明；组件标注与说明对应。

截图来自作者 2026-10-23 正式原型排行榜页，无弹窗，来源摘要为 `d840aa23`。脱敏只在浏览器临时副本中替换品牌、业务文本与媒体；左侧具体路由按原层级统一显示为“一级页面、二级页面、三级页面”，保留缩进、层级线与选中状态。原有布局、尺寸、颜色和字体保留，未修改正式源文件。截图展示该原型的真实评审外壳，不把其尺寸或配色推广为所有项目要求。

## 线框稿分支

![线框稿分支布局示意：左侧页面路由、中央线框画布、画布外备注与箭头](images/stage2-wireframe-branch.png)

线框分支与高保真分支并列，不是高保真沙盒中的第四种查看模式。常见输入有两种：

1. **确认 PRD → 独立线框**：先核对需求、范围和 UI 来源；没有既有 UI 的新页面标为布局提案。
2. **已有原型 → 只读派生线框**：保留源视图的结构、位置、尺寸和规则，降低视觉材质，不改写原型。

左侧保留页面路由，用于切换页面与状态；中央呈现当前线框画布；备注卡位于产品画布外，箭头对应真实组件。路由和备注均属于评审外壳，不是产品页面的一部分。本图是会议室场景的布局提案，不宣称还原某份现有业务 UI。

## 包能力与图片边界

GeorgePM v0.1.0 提供 `pm-define`、`pm-prototype`、`pm-deliver` 三个 Skill。配图补充了沙盒布局与线框扩展路线的介绍，没有增加第四个 Skill；独立线框生产器及一键转换器不在本包内。

图片说明与 Skill 指引不能替代真实宿主安装、浏览器交互、来源保真或生产服务验证。会议室的三阶段文字契约见 [示例目录](../examples/meeting-room/README.md)。

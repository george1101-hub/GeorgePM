# 来源与可分发范围

GeorgePM 是作者三阶段工作流的公开精简重组：需求定义 → 交互原型 → 研发交付。核心方法包含范围继承、需求追溯、原型占位边界、真实截图与验收证据分离。

公开包不复制原业务 PRD、真实数据、历史截图或私人记忆，也不捆绑外部 Skill/组件库。模板及会议室预约走读是为本包编写的通用内容；项目特有的品牌、颜色、像素间距、模型名称与本机路径没有作为公共规则继承。

Skill 属于模型工作指引，不是能保证输出质量的独立程序。生成结果的权属与再分发范围仍取决于输入材料、外部素材和所用服务条款。本包 MIT 许可只覆盖本仓库维护者有权授权的内容。

兼容布局采用 OpenAI 和 Claude 官方文档公开的插件/Skill 结构。没有绑定单一模型，不要求第三方授权密钥；安装前可完整审阅仓库内容。
